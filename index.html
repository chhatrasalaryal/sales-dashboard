About this data
  • This is a widely used synthetic sample dataset of retail orders, not real company sales. Each item type has one fixed unit price and cost, so margins differ by item but are almost identical across regions, channels and order priorities.
  • Some order IDs appear twice in the file. The dashboard counts every row as given.
  • Days to ship are spread evenly from 0 to 50 and don't vary with order priority.

Built from the synthetic "1,000,000 Sales Records" sample dataset, aggregated by build.py.
